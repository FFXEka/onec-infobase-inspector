# Начало работы

Скачайте готовую обработку из Releases и откройте EPF в нужной базе 1С. Требуются полные права. Архив Source code содержит исходники; для обычного использования выбирайте EPF или комплект с EPF и лицензиями.

## Посмотреть заполненность базы

1. При необходимости задайте период и организацию на вкладке **Отбор**.
2. Выполните **Сканировать… → Основные**.
3. На сводной таблице или странице вида метаданных выберите интересующий объект.
4. Командами меню **Открыть…** перейдите к списку или подробностям.

Изменение отбора не пересчитывает уже полученный результат. Повторите сканирование. Объекты без подходящего поля даты или организации при активном отборе пропускаются.

## Сравнить количество записей до и после операции

1. Выполните основной скан.
2. Выберите **Сравнить… → Сохранить текущий скан в памяти (активировать режим сравнения)**.
3. Выполните нужную операцию в базе и повторите основной скан с теми же отборами.
4. Посмотрите колонки **Для сравнения** и **Разница**. Разница — текущее количество минус эталон.

Повторный скан не заменяет эталон. Между сеансами эталон переносится командами сохранения и загрузки скана в меню **Сравнить…**. Обычная печатная форма и экспорт в Excel не заменяют файл скана MXL.

Сравнивается количество, а не содержимое записей. Обработка не доказывает полноту обмена и не выявляет изменения реквизитов при неизменном количестве объектов.

## Изучить объект

Команда **Открыть… → Объект подробно** показывает структуру выбранного объекта. Доступные страницы включают реквизиты, табличные части, движения и зависимые объекты. Подробные счётчики не ограничиваются отбором основной формы.

В управляемом универсальном списке флажок **Отображать количество строк табличных частей** включает дополнительные числовые колонки, отбор и сортировку по ним. При выключении удаляются и связанные с этими колонками настройки. В обычном списке счётчики рассчитываются для отображаемых строк; отбора и сортировки по ним нет.

## Системные и дополнительные сведения

Используйте соответствующие команды меню **Сканировать…**. Состав сведений зависит от конфигурации, платформы, ОС и разрешений. Недоступное значение не следует трактовать как ноль или отсутствие объекта.

Сканирование читает данные. Редактор констант сохраняет значение только по команде **Записать**; штатные формы конфигурации также могут изменять данные. При подтверждении разрешений на открытие внешней обработки учитывайте правила вашей организации.

Полное описание команд и ограничений — во встроенной справке EPF и [help.html](help.html).
