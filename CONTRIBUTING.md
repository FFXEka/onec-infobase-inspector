# Ошибки, предложения и изменения

Создавайте Issues для ошибок и предложений. Укажите версию обработки, полную версию платформы, конфигурацию, обычное или управляемое приложение, вид клиента, ОС клиента/сервера и действия для воспроизведения. Не прикладывайте рабочие базы, пароли, строки подключения и необезличенные сканы.

Перед изменением кода прочитайте [описание сборки](docs/BUILD.md). В версии 4.137 есть обычные формы с модулем внутри `Form.bin`; это часть исходников, редактируемая Конфигуратором.

Сохраняйте совместимость 8.2/8.3 и обычных/управляемых форм. Закомментированные области и адаптеры совместимости намеренны. При изменении запросов проверяйте их выполнением в тестовой 1С: статический анализ BSL не подтверждает синтаксис и исполнение запросов.

В pull request опишите проблему, изменение и фактически выполненные проверки. Для собственного кода проекта действует GPL версии 3; права на сторонние материалы должны быть совместимы с их включением и явно указаны.
