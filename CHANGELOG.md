# Изменения

## 4.137

Первый выпуск в отдельном репозитории `onec-infobase-inspector`.

Изменения относительно 4.136:

- В управляемом универсальном списке счётчики строк табличных частей включаются отдельным флажком. По умолчанию запрос не содержит соответствующих агрегатов и соединений.
- При выключении счётчиков удаляются использующие их отборы и сортировки; настройки по реальным реквизитам сохраняются.
- Обработаны коллизии имён вычисляемых колонок с реквизитами объекта и вложенные условия отбора.
- Уточнены условия периода и организации, подпись флажка и встроенная справка.

Обычный универсальный список сохраняет расчёт счётчиков для отображаемых строк.

При переносе версии на GitHub исходный EPF не изменён. Добавлены документация репозитория, GPL v3 для авторского кода и уведомление о картинке БСП под CC BY 4.0.
